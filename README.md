# Tableau EDA Project

This repository contains exploratory data analysis (EDA) work and visualizations to support data storytelling and decision-making using **Python** and **Tableau Public**.

---

## 📌 Project Overview

The project begins with Python-based exploratory data analysis (EDA) in Jupyter Notebook to clean, preprocess, and understand the dataset.
The cleaned dataset is then exported and uploaded into **Tableau Public** for interactive visualization and further analysis.

---

## 🛠️ Tools & Libraries

* **Python**: `pandas`, `numpy`, `matplotlib`, `seaborn`
* **Jupyter Notebook**: for EDA and data cleaning
* **Tableau Public**: for visualization and dashboards

---

## 📂 Repository Structure

```
├── EDA_Tableau.ipynb   # Jupyter Notebook with data cleaning & EDA
├── data/               # Raw and cleaned data files
└── README.md           # Project documentation
```

---

## 🚀 How to Use

1. Clone the repo:

   ```bash
   git clone https://github.com/yourusername/tableau-eda-project.git
   cd tableau-eda-project
   ```
2. Install dependencies:

   ```bash
   pip install pandas numpy matplotlib seaborn jupyter
   ```
3. Open the notebook:

   ```bash
   jupyter notebook EDA_Tableau.ipynb
   ```
4. Export cleaned dataset (`.csv`) and load it into **Tableau Public** for visualization.
